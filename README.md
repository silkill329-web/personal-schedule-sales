# 予定と収支 PWA（試作品）

## 含まれるファイル
- `index.html`：画面・カレンダー・案件・売上/利益計算など
- `manifest.json`：ホーム画面追加用の設定
- `sw.js`：PWAの簡易キャッシュ設定

## 機能
- 月間カレンダーと日別予定（仕事・プライベート・その他）
- 案件登録（取引先、案件日、売上、期限、人件費、経費、請求書番号、入金状況）
- 案件の利益自動計算
- 月別の売上・利益・人件費・経費・未入金集計
- JSONバックアップと復元
- ブラウザ内保存（localStorage）

## iPhoneで使う方法
PWAのホーム画面追加にはHTTPSで公開する必要があります。iPhone単体で最も簡単な手順の一例：
1. GitHubアカウントを作成/ログインする。
2. 新しいリポジトリを作成（例：`personal-schedule-sales`）。公開リポジトリなら無料のGitHub Pagesを利用できます。実データを含めないでください。
3. このZIPを展開し、`index.html`、`manifest.json`、`sw.js` の3ファイルをリポジトリ直下にアップロードする。
4. リポジトリの Settings → Pages → Build and deployment で `Deploy from a branch`、`main`、`/(root)` を選んで保存する。
5. 公開URLが発行されたらiPhoneのSafariで開き、共有ボタン →「ホーム画面に追加」を選ぶ。
6. 追加したアイコンから開いて動作確認する。

GitHub Pagesのメニュー表記は変更される場合があります。URLはリポジトリ名に応じて変わります。

## 重要な注意
- データはログインアカウントやクラウドに保存されず、使っているブラウザ内に保存されます。同じURLでも、通常のSafariとホーム画面から開いたPWAで保存領域が異なる場合があります。
- ブラウザのデータ消去や端末故障などでデータが失われる可能性があります。定期的に「設定」からJSONバックアップを保存してください。
- 端末内保存はプライベートな保存を保証するものではありません。端末のパスコードを設定し、共有端末では使用しないでください。
- この試作品は正式な会計・請求書発行ソフトではありません。消費税、源泉徴収、複数税率、入金の一部消込、継続案件、月をまたぐ計上基準などは未対応です。
- 利益は案件日が属する月の売上から人件費とその他経費を引いた概算です。未入金額は登録案件の売上全額を集計します。
